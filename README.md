Boothbnb is a development project that is built for vendors and host to discover, book and manages the booth event booth spaces.

The backend uses Node.js, Typescript and Express to build reliable REST API to ensure seamless interaction between frontend and backend. Postgresql and prisma is used for database and orm integration for smooth migration. Cron is also utilized for scheduling task that run periodically.

Other tools such as resend.dev that allow sending, tracking and managing email is used. Stripe for payment processing that allow onboarding process, currency exchange. Frankfurter.dev for currency conversion to provide estimated cost for prices. Cloudinary is used for image hosting and management.

The database is hosted at neondb.
The backend is hosted at Vercel :https://api.dev.boothbnb.online/
